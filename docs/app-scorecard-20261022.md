## 剩餘風險（交畀他人測試前要知道）

1. 線上 widget 需要 `scout-admin-blue.vercel.app`；離線時只有後備文字，唔會自動補交。
2. 進度只存喺單一裝置，換機／清 cache 會冇；UI 已寫明。
3. `img/fig/fire-circle.avif` 係平面示意圖（由 `img/dia/fire-circle.avif` 複製），唔係相片。
4. 制服章位以《儀容與制服手冊》原文為準；未核實的章形不會自繪。
5. 尚未接入 CI；合併前要人手跑 `npm test`。
